# Vertex Shifa

**فيرتكس شفا** — a multi-product health platform for Syria, built by Vertex.

V1 ships the first product, **Vertex Shifa Clinic**: clinic and doctor management that keeps working without internet, with the **Vertex Shifa** patient app (Android and iOS), public clinic booking pages and the platform console. Hospitals, labs and pharmacies follow as new products on the same platform core.

First market: Azaz, northern Aleppo. Arabic-first.

## Status

Phase 0 — Foundation. The repository holds the product scope, the architecture decisions and the working method; the code scaffold follows. See [`docs/ROADMAP.md`](docs/ROADMAP.md).
